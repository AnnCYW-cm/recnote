# 业务规则与需求追踪

本文是录见 `0.2.x` 稳定业务规则的统一索引。其他 UML 文档可以引用规则 ID，不应把同一条规则改写成互相冲突的版本。

规则只覆盖会影响用户结果、隐私、交付或验收的稳定行为，不收录按钮位置、宣传文案或所有算法参数。

## 输入规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-IN-01` | Web 只接受 MP4、MOV、WebM；文件必须非空且不超过 500 MB | `lib/video-analysis.ts` 的 `validateVideoFile()` | E2E 有效输入主链；边界参数化测试待补 |
| `BR-IN-02` | 视频元数据必须包含正数时长与尺寸，且时长不超过 5 分钟 | `lib/video-analysis.ts` 的 `waitForVideoReady()`、`analyzeVideo()` | E2E 有效输入主链；时长与元数据异常测试待补 |
| `BR-IN-03` | 扩展名或 MIME 合法不代表编码可用；最终是否可处理由当前浏览器解码能力决定 | `HTMLVideoElement` 元数据与错误事件 | 构建检查；需补跨浏览器样本矩阵 |

## 分析规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-AN-01` | Web 根据时长生成 12–120 个低分辨率采样点 | `lib/video-analysis.ts` 的采样计划 | E2E 真实视频链路 |
| `BR-AN-02` | 分析结果保留 1–10 张候选；几乎静态的录屏只保留一张，不为满足数量制造重复步骤 | `selectCandidateSamples()` | E2E“静态录屏不会被硬凑” |
| `BR-AN-03` | 候选分数只表示视觉变化启发式结果，不表示系统理解了点击、操作或业务语义 | `AnalyzedVideoFrame.score` 与 README 能力边界 | E2E 检查能力边界文案 |
| `BR-AN-04` | 分析成功、失败或取消后都必须清理媒体 `src` 并撤销临时 Blob URL | `analyzeVideo()` 的 `finally` | 代码审查；取消链路 E2E 可继续补强 |

## 编辑与复核规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-ED-01` | 真实视频步骤的默认正文是人工占位说明；所有纳入步骤必须替换为真实说明后才能交付 | `localEditorSource()`、`localStepCopyReady` | E2E 真实视频先被内容门禁阻止 |
| `BR-ED-02` | 至少保留一个标题和正文均非空的步骤；隐藏步骤不参加门禁计数和导出 | `includedSteps`、`contentReady` | E2E 主链；建议补全隐藏步骤专项测试 |
| `BR-ED-03` | 调整步骤顺序不会自动撤销文案或隐私复核；恢复隐藏步骤后重新参加门禁计数 | `moveStep()` 与派生集合 | 类型检查；建议补状态专项测试 |
| `BR-RV-01` | 修改步骤标题或正文后，该步骤进入待核对状态，历史文案确认立即失效 | `updateStepCopy()` | E2E“文案已修改 · 待核对” |
| `BR-RV-02` | 修改文章标题或摘要后，文章级文案确认立即失效 | `updateArticleCopy()` | E2E 标题摘要确认链路 |
| `BR-RV-03` | 每张纳入成稿的截图都必须由用户逐张确认隐私；系统不会自动识别或自动打码 | `privacyReviewedIds`、`privacyReady` | E2E 0/6 阻塞与逐张确认 |

## 交付门禁与导出规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-GT-01` | `publishReady` 只有在内容完整、时间戳齐全、截图齐全、修改内容已复核、纳入截图已完成隐私复核五项同时通过时为真 | `contentReady`、`timestampsReady`、`screenshotsReady`、`copyReviewReady`、`privacyReady` | E2E 完整交付门禁 |
| `BR-GT-02` | Markdown、富文本和 ZIP 三种交付请求必须经过同一套门禁校验；失败时应指出具体阻塞项 | `validateDelivery()`、`requestDelivery()` | E2E 内容与隐私阻塞提示 |
| `BR-EX-01` | Markdown 写入剪贴板；示例使用公开同源图片地址，真实视频使用 `images/step-XX.jpg` 相对路径并提示用户配合 ZIP 素材包 | `buildMarkdown()`、`markdownImagePath()`、`navigator.clipboard.writeText()` | E2E ZIP 内 Markdown 路径检查；剪贴板权限测试待补 |
| `BR-EX-02` | 公众号排版优先写入 `text/html` 与 `text/plain`；富文本不可用时降级复制 Markdown | `writeRichClipboard()` | 构建检查；建议补剪贴板降级专项测试 |
| `BR-EX-03` | ZIP 至少包含 `教程.md`、`公众号预览.html`、`使用说明.txt` 和 `images/` 下全部纳入截图 | `createTutorialZip()` | E2E 解压并核对 Markdown、图片数量与 JPEG 文件头 |
| `BR-EX-04` | 交付成功必须按格式判断：Markdown 写入成功只代表文本交付；富文本写入成功代表剪贴板交付但不能保证目标平台保留图片；真实视频需要图文素材完整时，以可解压且图片齐全的 ZIP 为准 | `requestDelivery()` 的成功提示、真实视频 Markdown 路径与 ZIP 契约 | E2E 验证 ZIP 完整性；目标编辑器试粘贴需人工验收 |

## 持久化与隐私规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-PS-01` | 只有自有示例草稿写入 `localStorage`；键为 `recnote-demo-draft-v5-muwa-board`，版本为 `2` | `UploadView`、`EditorView` 草稿逻辑 | E2E 每次清理本地存储；建议补恢复专项测试 |
| `BR-PS-02` | 真实视频、候选截图和真实视频草稿只存在于当前浏览器会话；刷新或关闭后不能恢复 | `source.kind === 'local'` 分支与 `PRIVACY.md` | 架构审查；建议补刷新行为测试 |
| `BR-PS-03` | 示例草稿保存文字、步骤顺序与纳入状态、当前选择、编辑模式和复核状态；时间戳、图片、图片高度与置信度从受控示例常量恢复 | `StoredDraft` 与恢复映射 | 类型检查；损坏草稿测试待补 |
| `BR-PR-01` | Web 当前没有视频上传接口、媒体处理服务器或第三方模型调用 | Web 模块、`.openai/hosting.json`、`PRIVACY.md` | 依赖与部署审查；E2E 能力边界文案 |
| `BR-PR-02` | 教程内容只在用户主动复制或下载时被带出录见：复制会写入系统剪贴板，下载会生成本地文件；是否粘贴到外部应用不可观测。示例字段子集会按 `BR-PS-01` 自动写入同源 `localStorage` | `requestDelivery()`、示例草稿 effect、`PRIVACY.md` | 代码审查 |
| `BR-PR-03` | 隐私确认是人工声明，不构成自动检测结果；发布前责任不能转嫁给算法 | 门禁文案与 `PRIVACY.md` | E2E 逐张人工确认 |

## 恢复与可修复性规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-RC-01` | 首页只为版本兼容的自有示例草稿显示继续入口；无效 JSON 会被清除，恢复时缺失字段从受控示例回退 | `UploadView` 与 `EditorView` 草稿读取逻辑 | 恢复与损坏草稿专项测试待补 |
| `BR-RC-02` | 当前 Web 没有候选池、手工补帧或截图替换；关键步骤漏检或候选画面不可用时，只能重新分析、重录，或在录见外补图 | 当前编辑器能力与 README 路线图 | 产品验收；对应产品内恢复测试要在能力实现后补充 |

## CLI 规则

| 规则 ID | 规则陈述 | 当前依据 | 自动化证据 |
| --- | --- | --- | --- |
| `BR-CLI-01` | CLI 是独立本地工具，不被 Web 调用，不连接网络或模型 API | `cli/video_guide.py`、模块依赖图 | CLI 单元与合成视频测试 |
| `BR-CLI-02` | 输出目录必须不存在或为空，且不能是符号链接；CLI 不覆盖已有人工结果 | 输出目录校验 | CLI 安全测试 |
| `BR-CLI-03` | CLI 输出 `metadata.json`、`candidates.json`、`review.html`、`model_prompt.md` 与 `screenshots/` | 输出写入函数 | CLI 产物测试 |
| `BR-CLI-04` | 候选截图初始隐私状态统一为 `unreviewed`；原视频不复制到输出目录，元数据不保存绝对路径 | manifest 生成与安全声明 | CLI schema 与隐私测试 |

## 当前能力基线

| 能力 | `0.2.x` 状态 | 产品说明 |
| --- | --- | --- |
| 浏览器本地读取真实视频 | 已实现 | 受 500 MB、5 分钟和浏览器编码支持限制 |
| 视觉变化候选筛选 | 已实现 | 不是操作语义识别 |
| 候选画面转教程步骤 | 已实现，机械映射 | 正文仍需人工补全 |
| 编辑、排序与隐藏步骤 | 已实现 | 尚无手工新增帧或替换截图 |
| 文案复核与隐私门禁 | 已实现，人工完成 | 没有自动审核或自动脱敏 |
| Markdown、富文本、ZIP | 已实现 | 最终发布发生在系统外部 |
| 示例草稿恢复 | 已实现 | 只保存字段子集 |
| 真实视频本地项目与最新快照 | 未实现 | V1 To-Be 待验证目标；不承诺完整版本树 |
| 候选池、手工增删帧、截图替换 | 未实现 | V1 To-Be 待验证目标 |
| 可插拔多模态语义建议 | 未实现 | V1 默认关闭的实验支路，受 `BR-FU-*` 约束 |
| 裁剪、标注和人工遮挡 / 模糊 | 未实现 | V1 To-Be 待验证目标；不代表自动隐私识别 |
| Docker 自托管与可选服务端处理 | 未实现 | 延后方向，不进入最小 V1 |
| 用户、组织、权限、审批与计费 | 未定义 | 不应被描述为现有或已排期能力 |
