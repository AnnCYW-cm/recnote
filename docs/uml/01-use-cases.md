# 用例说明

Mermaid 没有稳定的标准 `usecaseDiagram` 语法。为保证 GitHub 可以直接阅读和审查，本文件用正式用例表代替无法原生渲染的椭圆用例图。

## 参与者

### 产品角色

| 参与者 | 当前实现 | 目标 |
| --- | --- | --- |
| 教程创作者 | 当前主要用户；匿名、单人 | 把一段软件录屏整理为可编辑、可复核、可交付的图文教程 |
| 文案审核者 | 当前与教程创作者是同一人 | 确认被修改的标题、摘要和步骤文案与画面一致 |
| 隐私审核者 | 当前与教程创作者是同一人 | 逐张确认纳入成稿的截图适合对外使用 |
| 发布者 | 当前与教程创作者是同一人 | 选择交付格式并把结果带到外部平台 |
| 教程读者 | 系统外部角色 | 使用最终教程完成任务；当前产品不观测其行为 |
| CLI 使用者 | 独立高级路径 | 在本机离线、可复现地提取更多候选截图和评审产物 |

“示例体验者”不是独立权限角色，而是教程创作者在没有真实视频时的一种体验状态。当前没有用户、组织、审核分工或权限模型。

### 工程角色与外部环境

| 参与者或环境 | 作用 |
| --- | --- |
| 项目维护者 | 修改算法、界面、规则或导出格式，并通过自动化测试验证边界 |
| 浏览器媒体能力 | 解码用户选择的视频，并提供 Canvas、剪贴板和下载能力 |
| 本地文件系统 | 保存用户下载的 ZIP 或 CLI 输出 |
| 外部发布平台 | 接收用户主动带出的富文本、Markdown 或素材包；不在录见控制范围内 |

## UC-01：选择并校验本地录屏

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 用户已在设备上拥有 MP4、MOV 或 WebM 文件 |
| 触发 | 用户选择文件或把文件拖入上传区域 |
| 主流程 | 校验扩展名或 MIME 类型、非空文件、文件不超过 500 MB，然后允许开始分析 |
| 失败路径 | 格式不支持、文件为空或超过上限时，清除选择并显示错误 |
| 后置条件 | 文件仍在用户设备上，只把浏览器 `File` 引用交给后续流程 |
| 关联规则 | `BR-IN-01`–`BR-IN-03`、`BR-PR-01`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-02：在浏览器本地提取候选画面

| 项目 | 说明 |
| --- | --- |
| 前置条件 | UC-01 成功；浏览器能够解码所选视频编码 |
| 触发 | 用户点击“在本地分析这段录屏” |
| 主流程 | 读取元数据；生成 12–120 个采样点；灰度化；计算全局与 4×4 局部差异；筛选视觉上不同且时间分布合理的候选；生成最大宽度 1600 px 的 JPEG 截图 |
| 特殊路径 | 画面几乎静止时只保留一张候选，不为满足数量而制造重复步骤 |
| 失败路径 | 解码失败、超过 5 分钟、读取或 seek 超时、Canvas 不可用、用户取消 |
| 后置条件 | 生成 `VideoAnalysisResult`；原视频未上传；临时 Blob URL 被释放 |
| 关联规则 | `BR-AN-01`–`BR-AN-04`、`BR-PR-01`、`BR-RC-02`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-03：编辑教程结构与文案

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 已从真实视频生成候选步骤，或已进入自有示例工作台 |
| 触发 | 用户修改文章标题、摘要、步骤标题或说明 |
| 主流程 | 选择步骤；修改文案；调整顺序；隐藏或恢复步骤；在编辑与成稿预览之间切换 |
| 业务规则 | 真实视频步骤的占位说明必须替换；隐藏步骤不参与门禁计数和导出 |
| 复核规则 | 任何已确认文案再次修改后，对应的“已复核”状态立即失效 |
| 后置条件 | React 状态中形成有序的 `TutorialStep` 集合 |
| 关联规则 | `BR-ED-01`–`BR-ED-03`、`BR-RV-01`–`BR-RV-02`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-04：复核文字与截图隐私

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 至少有一个纳入成稿的步骤 |
| 触发 | 用户准备复制或下载教程 |
| 主流程 | 如文章标题、摘要或步骤文案被修改，对相应内容确认其与画面一致；逐张确认截图无敏感信息 |
| 通过条件 | 内容完整、时间戳齐全、截图齐全、全部修改已复核、全部纳入截图已做隐私复核 |
| 失败路径 | 任一条件不满足时，阻止交付并提示下一项需要完成的工作 |
| 边界 | 系统只记录人工确认，不会自动识别或自动打码敏感信息 |
| 关联规则 | `BR-RV-01`–`BR-RV-03`、`BR-GT-01`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-05：导出教程

| 项目 | 说明 |
| --- | --- |
| 前置条件 | UC-04 的五项门禁全部通过 |
| 触发 | 用户选择 Markdown、公众号排版或独立图文包 |
| Markdown | 生成带图片路径的 Markdown 并写入剪贴板 |
| 公众号排版 | 优先写入 `text/html` 与 `text/plain`；浏览器不支持富文本剪贴板时降级为 Markdown |
| ZIP | 生成 `教程.md`、`公众号预览.html`、`使用说明.txt` 与 `images/`，然后触发本地下载 |
| 后置条件 | 交付物只在用户主动请求时生成，并写入系统剪贴板供用户带到外部应用，或下载到本地文件系统 |
| 关联规则 | `BR-GT-02`、`BR-EX-01`–`BR-EX-04`、`BR-PR-02`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-06：体验或恢复自有示例

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 不要求提供视频；示例素材来自仓库内木瓦任务板自有案例 |
| 主流程 | 播放示例处理过程，进入六步预置初稿；编辑后以 250 ms 防抖写入 `localStorage` |
| 恢复路径 | 首页检测到版本兼容的草稿后，允许继续编辑 |
| 清理路径 | 用户确认后清空示例草稿并重新开始 |
| 边界 | 只有示例草稿持久化；真实视频草稿不会写入 `localStorage` |
| 关联规则 | `BR-PS-01`–`BR-PS-03`、`BR-RC-01`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-07：使用 CLI 离线提取候选

| 项目 | 说明 |
| --- | --- |
| 前置条件 | Python 3.10+、`ffmpeg`、`ffprobe` 可用；输出目录不存在或为空 |
| 触发 | 用户运行 `python3 cli/video_guide.py VIDEO --output DIRECTORY` |
| 主流程 | 读取元数据；场景检测；灰度周期采样；MAD 分析；信号聚类；时间覆盖；视觉去重；候选限额；抽取高清 JPEG；写入评审产物 |
| 失败路径 | 缺少工具、输入无效、输出目录不安全、ffmpeg 失败时返回非零状态并显示错误 |
| 后置条件 | 本地生成 `metadata.json`、`candidates.json`、`review.html`、`model_prompt.md` 和 `screenshots/` |
| 关联规则 | `BR-CLI-01`–`BR-CLI-04`，见[业务规则与需求追踪](09-business-rules-and-traceability.md) |

## UC-08：验证改动

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 已安装 Node.js 22.13+、Python 3.10+ 与 Playwright Chromium；完整 CLI 合成视频测试另需 `ffmpeg` 和 `ffprobe`，缺失时该测试会跳过 |
| 主流程 | 运行 CLI 测试、格式检查、lint、TypeScript 检查、生产构建和 Playwright 测试 |
| 后置条件 | 关键链路、发布门禁、ZIP 内容与静态视频降级行为均有自动化证据 |
| 关联规则 | 追踪全部受影响规则；该用例属于工程质量保证，不是最终用户旅程 |

## 尚未进入当前系统的目标能力

以下能力属于路线图或待验证方向，不应被描述为当前可用用例：

- 自动理解点击、输入和业务语义；
- 自动生成最终教程文案；
- 自动识别或打码隐私信息；
- 把真实视频草稿保存到云端项目历史；
- Web 调用 CLI 或服务端媒体处理队列；

## 持续有效的禁止性约束

无论未来是否接入模型，**未经用户明确同意，不得把视频或截图发送给第三方模型**。这是一条持续隐私约束，不是等待实现的路线图能力。详细前置条件见 `BR-FU-01`–`BR-FU-04`。
