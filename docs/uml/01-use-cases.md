# 用例说明

Mermaid 没有稳定的标准 `usecaseDiagram` 语法。为保证 GitHub 可以直接阅读和审查，本文件用正式用例表代替无法原生渲染的椭圆用例图。

## 参与者

| 参与者 | 目标 |
| --- | --- |
| 教程创作者 | 把一段软件录屏整理为可编辑、可复核、可交付的图文教程 |
| 示例体验者 | 不提供真实视频，使用木瓦任务板自有案例体验完整工作台 |
| CLI 使用者 | 在本机离线、可复现地提取更多候选截图和评审产物 |
| 项目维护者 | 修改算法、界面或导出格式，并通过自动化测试验证边界 |

| 编号 | 用例 | 主要参与者 | 结果 |
| --- | --- | --- | --- |

| UC-05 | 导出教程 | 教程创作者 | 获得 Markdown、公众号富文本或独立 ZIP 图文包 |

## UC-01：选择并校验本地录屏

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 用户已在设备上拥有 MP4、MOV 或 WebM 文件 |
| 触发 | 用户选择文件或把文件拖入上传区域 |
| 主流程 | 校验扩展名或 MIME 类型、非空文件、文件不超过 500 MB，然后允许开始分析 |
| 失败路径 | 格式不支持、文件为空或超过上限时，清除选择并显示错误 |
| 后置条件 | 文件仍在用户设备上，只把浏览器 `File` 引用交给后续流程 |

## UC-02：在浏览器本地提取候选画面

| 项目 | 说明 |
| --- | --- |
| 前置条件 | UC-01 成功；浏览器能够解码所选视频编码 |
| 触发 | 用户点击“在本地分析这段录屏” |
| 主流程 | 读取元数据；生成 12–120 个采样点；灰度化；计算全局与 4×4 局部差异；筛选视觉上不同且时间分布合理的候选；生成最大宽度 1600 px 的 JPEG 截图 |
| 特殊路径 | 画面几乎静止时只保留一张候选，不为满足数量而制造重复步骤 |
| 失败路径 | 解码失败、超过 5 分钟、读取或 seek 超时、Canvas 不可用、用户取消 |
| 后置条件 | 生成 `VideoAnalysisResult`；原视频未上传；临时 Blob URL 被释放 |

## UC-03：编辑教程结构与文案

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 已从真实视频生成候选步骤，或已进入自有示例工作台 |
| 触发 | 用户修改文章标题、摘要、步骤标题或说明 |
| 主流程 | 选择步骤；修改文案；调整顺序；隐藏或恢复步骤；在编辑与成稿预览之间切换 |
| 业务规则 | 真实视频步骤的占位说明必须替换；隐藏步骤不参与门禁计数和导出 |
| 复核规则 | 任何已确认文案再次修改后，对应的“已复核”状态立即失效 |
| 后置条件 | React 状态中形成有序的 `TutorialStep` 集合 |

## UC-04：复核文字与截图隐私

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 至少有一个纳入成稿的步骤 |
| 触发 | 用户准备复制或下载教程 |
| 主流程 | 如文章标题、摘要或步骤文案被修改，对相应内容确认其与画面一致；逐张确认截图无敏感信息 |
| 通过条件 | 内容完整、时间戳齐全、截图齐全、全部修改已复核、全部纳入截图已做隐私复核 |
| 失败路径 | 任一条件不满足时，阻止交付并提示下一项需要完成的工作 |
| 边界 | 系统只记录人工确认，不会自动识别或自动打码敏感信息 |

## UC-05：导出教程

| 项目 | 说明 |
| --- | --- |
| 前置条件 | UC-04 的五项门禁全部通过 |
| 触发 | 用户选择 Markdown、公众号排版或独立图文包 |
| Markdown | 生成带图片路径的 Markdown 并写入剪贴板 |
| 公众号排版 | 优先写入 `text/html` 与 `text/plain`；浏览器不支持富文本剪贴板时降级为 Markdown |
| ZIP | 生成 `教程.md`、`公众号预览.html`、`使用说明.txt` 与 `images/`，然后触发本地下载 |
| 后置条件 | 结果只在用户主动复制或下载时离开页面内存 |

## UC-06：体验或恢复自有示例

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 不要求提供视频；示例素材来自仓库内木瓦任务板自有案例 |
| 主流程 | 播放示例处理过程，进入六步预置初稿；编辑后以 250 ms 防抖写入 `localStorage` |
| 恢复路径 | 首页检测到版本兼容的草稿后，允许继续编辑 |
| 清理路径 | 用户确认后清空示例草稿并重新开始 |
| 边界 | 只有示例草稿持久化；真实视频草稿不会写入 `localStorage` |

## UC-07：使用 CLI 离线提取候选

| 项目 | 说明 |
| --- | --- |
| 前置条件 | Python 3.10+、`ffmpeg`、`ffprobe` 可用；输出目录不存在或为空 |
| 触发 | 用户运行 `python3 cli/video_guide.py VIDEO --output DIRECTORY` |
| 主流程 | 读取元数据；场景检测；灰度周期采样；MAD 分析；信号聚类；时间覆盖；视觉去重；候选限额；抽取高清 JPEG；写入评审产物 |
| 失败路径 | 缺少工具、输入无效、输出目录不安全、ffmpeg 失败时返回非零状态并显示错误 |
| 后置条件 | 本地生成 `metadata.json`、`candidates.json`、`review.html`、`model_prompt.md` 和 `screenshots/` |

## UC-08：验证改动

| 项目 | 说明 |
| --- | --- |
| 前置条件 | 已安装 Node.js 22.13+；端到端测试已安装 Chromium；完整 CLI 测试可选安装 ffmpeg |
| 主流程 | 运行 CLI 测试、格式检查、lint、TypeScript 检查、生产构建和 Playwright 测试 |
| 后置条件 | 关键链路、发布门禁、ZIP 内容与静态视频降级行为均有自动化证据 |

## 不属于当前系统的用例

以下能力仍是路线图，不应被描述为当前可用用例：

- 自动理解点击、输入和业务语义；
- 自动生成最终教程文案；
- 自动识别或打码隐私信息；
- 把真实视频草稿保存到云端项目历史；
- Web 调用 CLI 或服务端媒体处理队列；
- 未经用户明确同意把视频或截图发送给第三方模型。
