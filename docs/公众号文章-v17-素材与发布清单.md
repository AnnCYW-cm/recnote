## 关键事实守门线

- 7 张候选来自真实 CLI 运行。
- Web 中的 6 步教程是同一自有案例的预置数据。
- CLI 与 Web 尚未自动串联，语义转换层尚未实现。
- Web 选择文件只校验类型和文件名，不读取、不上传、不分析视频字节。
- 2.06 秒只是当前设备的一次墙钟记录，不是平均值或性能承诺。
- CLI 不调用网络或模型 API；这不代表在线 Web Demo 可以完全离线使用。
- 系统尚不支持自动脱敏，所有截图发布前仍需人工检查。

## 发布前检查

- 先部署包含全部正文图片的站点版本，再粘贴到 md.doocs。
- 确认 `07-editor-detail.png` 和全部正文配图的公开地址返回 200。
- 在 md.doocs 中从正文第 3 行开始粘贴，避免公众号标题重复。
- 逐张检查图片是否载入、是否清晰、是否出现横向溢出。
- 在公众号后台单独填写标题、摘要与“阅读原文”。
- 预览时至少检查一台 iPhone 宽度和一台 Android 宽度。
- 保留“真实 CLI 候选”和“Web 预置教程”尚未接通的说明，不得改成自动生成。
- 不使用第三方产品录屏作为主案例。
